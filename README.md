# Portfolio Website

## [Live Link](https://mukulbhatia-portfolio.netlify.app/)

## Description  
This is a personal portfolio website designed to showcase projects, technical skills, and achievements. The website is optimized for a smooth user experience with fast load times and enhanced email functionality for seamless communication.

## Features  
- Showcases projects, skills, and achievements  
- Optimized UI performance, reducing page load time by 35%  
- Enhanced email functionality for improved response efficiency  
- Fully responsive design using Tailwind CSS  

## Installation  
1. Clone the repository:  
   ```sh  
   git clone https://github.com/mukulbhatia799/My-Portfolio-website.git  
   cd My-Portfolio-website  
   ```

2. Install dependencies:  
   ```sh  
   npm install  
   ```  

3. Start the server:  
   ```sh  
   npm start  
   ```  

## Tech Stack  
- React.js  
- Tailwind CSS
